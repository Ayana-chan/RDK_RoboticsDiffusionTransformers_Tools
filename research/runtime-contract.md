## 执行关系

原版已有六图依次预处理并异步提交的能力。本改动将单板视觉方法拆成提交、收集和异常回收；六图提交后、第一次等待前，执行关节/状态准备和首轮动作适配器。图像适配器仍在视觉结果收齐后执行，后四轮动作准备仍依赖前一轮 solver。保留六图顺序、原六槽、五步去噪、全部模型及预处理表达式，不增加 Python 工作线程或跨请求并发。

调用方须串行使用同一实例；局部 `pending` 列表不是互斥锁，本改动不提供同一实例的线程安全保证。

成功提交的任务由 `finally` 尽力回收；`start` 或 `wait` 抛错时底层状态未知，该实例禁止继续提交，必须重建。Python 回收不等于底层 SDK 提供可靠取消。双板或自定义视觉回调仍按同步路径执行，本分支不宣称它们获得同样的重叠。
